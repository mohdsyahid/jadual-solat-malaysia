Jadual Solat Malaysia

Waktu solat harian untuk semua 60 zon JAKIM — data rasmi, dikemas kini setiap hari, dan percuma untuk digunakan oleh mana-mana aplikasi melalui JSON API.

JSON API percuma

Data penuh setahun untuk setiap zon tersedia sebagai JSON statik — sesuai untuk bot, app, atau skrip apa sahaja. Contoh (zon SGR01 = Selangor - Gombak/Petaling/Shah Alam):

https://mohdsyahid.github.io/jadual-solat-malaysia/data/SGR01.json

Senarai semua zon: https://mohdsyahid.github.io/jadual-solat-malaysia/data/zones.json. Gantikan kod zon dalam URL mengikut senarai tersebut. Data dikemas kini harian melalui GitHub Actions, sumber rasmi JAKIM e-solat.

Data dari JAKIM e-solat — logo JAKIM hak cipta Jabatan Kemajuan Islam Malaysia, digunakan untuk tujuan rujukan sumber.
